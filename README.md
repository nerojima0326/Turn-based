# 만조의 밤 — 리버스: 1999 풍 카드 턴제 전투

카드를 합성하고 열정을 모아 최종 술식으로 해파리 떼와 **만조의 여왕**을 쓰러뜨리는 브라우저 게임입니다.
설치나 빌드 없이 `index.html`을 브라우저로 열면 바로 실행됩니다. (GitHub Pages에도 그대로 올릴 수 있습니다.)

## 플레이 방법

- 매 턴 **행동력 3**: 카드를 눌러 선택하고, 한 번 더 누르거나 위로 끌어 올리면 사용합니다.
- **합성**: 같은 카드·같은 등급을 겹치면 ★이 오르고 열정 +1 (행동력 1 소모).
  카드를 써서 빈자리 양옆이 같은 카드가 되면 행동력 없이 **연쇄 합성**됩니다.
- **열정 5칸** → 손패 맨 왼쪽에 **최종 술식** 카드 등장.
- 적 머리 위 아이콘은 **다음 행동과 표적**입니다. ‼ 최종 술식이 예고되면 보호막·회복으로 대비하세요.
- **영감 상성**: 야수 → 식물 → 항성 → 암석 → 야수, 영혼 ↔ 지능 (우세 피해 +30%, 열세 -20%).
- 별 3개 조건: 승리 · 전원 생존 · 11턴 이내. 제한은 20턴입니다.

단축키: `1`~`9` 카드 · `Space` 실행 · `Z` 되돌리기 · `R` 초기화 · `Tab` 대상 변경 · `A` 자동 · `S` 배속 · `M` 소리 · `I` 적 정보 · `H` 도움말

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 구조 |
| `css/style.css` | 디자인 · 반응형 레이아웃 |
| `js/data.js` | 캐릭터 · 스킬 · 적 · 라운드 수치 (밸런스는 여기서 조정) |
| `js/engine.js` | 화면과 분리된 전투 규칙, 자동 전투 AI |
| `js/game.js` | 연출 · 입력 · UI |
| `js/sprites.js` | 코드로 그린 SVG 캐릭터와 아이콘 |
| `js/fx.js` | 파티클 · 흔들림 · 히트스톱 |
| `js/audio.js` | WebAudio로 합성하는 효과음과 배경음악 |

## 개발

```bash
node tools/test.js        # 전투 엔진 테스트
node tools/sim.js 1000    # 자동 AI로 1000판 돌려 승률·평균 턴 확인
```
